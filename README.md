# Program 300 Member Dashboard

A responsive, static member dashboard preview for Indiana residents. It introduces
Program 300, its stated mission, and planned benefit/resource areas without
implying that live services, eligibility, or member accounts are available.

## View the dashboard

Open `index.html` in a web browser. No dependencies or build step are required.

## Preview limitations

The dashboard is informational only. Member benefits, eligibility, accounts,
resource listings, and services are not connected or guaranteed. New World Order
Private Government DAO LLC is presented as an independent organization, not a
government agency. The navigation sections for member portal, resource catalog,
development plans, referrals, organizations, audit transparency, and contact are
informational placeholders, not operational features.
